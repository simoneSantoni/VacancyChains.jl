Visualization API

All plotting functions are reserved by name in v0.1.0 and currently raise not implemented. This page documents what each plot is meant to render so that the public API is stable from the package's first release. Implementations will land as Plots.jl recipes (or CairoMakie equivalents) in a follow-up revision.

The data inputs each plot consumes are already produced by the exploratory and estimation functions:

PlotConsumesProduced by

plot_length_distributionchain_lengths(::ChainSet)chain_lengths
plot_mobilitymobility_table(::ChainSet)mobility_table

Splitting "compute" from "draw" follows the convention used in REM.jl and keeps the plotting surface independent of any particular plotting backend.

Descriptive plots

plot_chain_tree

Tree diagram of a single chain, rendered as a left-to-right cascade in which each node is a position and each edge is a move. The intended look follows White (1970), Chapter 5: the seed vacancy at the root, terminal external hires or abolitions at the leaves. Useful for case-study presentation of individual chains and for teaching the basic vacancy-propagation mechanism.

VacancyChains.plot_chain_tree — Function
plot_chain_tree(chain::Chain)

Tree diagram of a single chain. Not yet implemented.

source

plot_length_distribution

Histogram of chain lengths across a ChainSet. The empirical distribution is the central descriptive statistic in Chase (1991), figure 1, and is what the planned fit_chain_length estimator will be calibrated against.

VacancyChains.plot_length_distribution — Function
plot_length_distribution(cs::ChainSet)

Histogram of chain lengths. Not yet implemented.

source

plot_mobility

Flow diagram of position-to-position (or stratum-to-stratum) mobility, defaulting to a Sankey/alluvial layout. This view of mobility data is the one popularised by Cheng & Park (2020): treat the mobility table as a weighted directed network of positions and visualise it as flows between them. Other layouts (:chord, :matrix) may be added.

VacancyChains.plot_mobility — Function
plot_mobility(cs::ChainSet; layout::Symbol=:sankey, by=nothing)

Flow diagram of stratum-to-stratum mobility. layout=:sankey requests a Sankey/alluvial layout; other layouts (:chord, :matrix) may be added. Not yet implemented.

source

plot_stratum_flows

Heatmap of stratum-to-stratum transition counts, projected through a PositionAttribute. Complements plot_mobility when the number of strata is small enough that a heatmap reads more clearly than a Sankey. Stratum definitions typically follow the rank/grade conventions of Stewman (1986) or Smith (1983).

VacancyChains.plot_stratum_flows — Function
plot_stratum_flows(cs::ChainSet, attr::PositionAttribute)

Heatmap of stratum transition counts. Not yet implemented.

source

plot_termination

Bar chart of the proportion of chains terminating in each kind from TERMINATION_KINDS. The split between external hire and abolition is the descriptive statistic that lets one diagnose whether mobility is being driven by external recruitment or by structural shrinkage of the position set — the question motivating Konda & Stewman (1980)'s opportunity model.

VacancyChains.plot_termination — Function
plot_termination(cs::ChainSet)

Bar chart of chain termination kinds. Not yet implemented.

source

Estimation-output plots

plot_coefficients

Coefficient plot with 95% confidence intervals. Generic over any fitted result that supports coef and stderror; the rendering convention matches ggcoef / coefplot in the R/Stata ecosystems.

VacancyChains.plot_coefficients — Function
plot_coefficients(result)

Coefficient plot with 95% confidence intervals. Not yet implemented.

source

plot_transition_matrix

Heatmap of estimated transition probabilities from a MarkovResult. The diagonal carries the "stay" probabilities (immobility within a stratum); off-diagonal cells carry mobility. Following McFarland (1970), the recommended diagnostic is to overlay the expected diagonal under perfect mobility and examine the gap.

VacancyChains.plot_transition_matrix — Function
plot_transition_matrix(result::MarkovResult)

Heatmap of estimated transition probabilities. Not yet implemented.

source

plot_fitted_lengths

Fitted vs. observed chain length distribution. Compares the empirical histogram from chain_lengths against the predictive distribution implied by a fitted fit_chain_length (or fit_opportunity) model. The gap between the two — particularly in the tails — is the central diagnostic used by Chase (1991) when comparing vacancy-chain models across systems.

VacancyChains.plot_fitted_lengths — Function
plot_fitted_lengths(result)

Fitted vs. observed chain length distribution. Not yet implemented.

source

plot_residuals

Diagnostic residual plot. Shape and content depend on the model: for a Markov fit, deviation residuals on the cell counts; for a chain-length regression, Pearson or quantile residuals on the count distribution.

VacancyChains.plot_residuals — Function
plot_residuals(result)

Diagnostic residual plot. Not yet implemented.

source

References

The visualization conventions follow the canonical descriptions in White (1970), Chase (1991), McFarland (1970), Stewman (1986), and Cheng & Park (2020). Full citations are on the References page.
